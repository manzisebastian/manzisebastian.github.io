Projects

  • BCRA_bot
    I developed a Twitter bot (@BCRA_bot) that tweets daily updates of Argentina's monetary statistics, together with weekly and monthly analyses.
    Originally, data was extracted using web scraping and leveraging third-party APIs. Beginning in 2024, data is gathered using the Central Bank of Argentina (BCRA)'s official API.
    The bot is hosted in Google Cloud Platform, and run with Google Cloud Scheduler.

    Due to Twitter's policy changes regarding bots, it may sporadically go offline.
    • #MacroeconomicAnalysis
    • #MonetaryStatistics
    • #MoneyMarket
  • EcoBici
    I conducted a comprehensive data analysis of EcoBici, the public bike sharing program of Buenos Aires, uncovering fascinating patterns hidden within over 16 million individual rides.
    The first goal of the project was to find patterns in user behavior and trip characteristics—exploring factors like trip duration, time of day, weekdays vs. weekends, and seasonal trends—to understand how, when, and why people rely on this service.
    Later on, the project evolved to include an impact evaluation approach. The next step? Assessing how improved cycling infrastructure could boost daily EcoBici usage, paving the way for smarter urban mobility solutions.
    • #TransportEconomics
    • #Cycling
    • #UrbanEconomics
  • Ma-py-tas
    Since 2020, I’ve immersed myself in the world of geospatial data analytics, creating (perhaps a few too many) maps along the way. The topics I’ve explored are diverse, ranging from the locations of barbecues and blooming jacarandás in Buenos Aires to Argentina’s vast hydrocarbon reservoirs.
    This project brings together an almost-complete collection of these maps, each one a snapshot of data-driven storytelling through geography.

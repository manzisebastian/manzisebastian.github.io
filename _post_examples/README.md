# Post examples (al-folio template)

These are the demo posts that ship with the al-folio theme. They were moved out of
`_posts/` so they stop appearing on the blog, but kept here as a reference for how to
use each post feature.

**This folder is ignored by Jekyll** (it starts with `_` and is not a collection), so
nothing here is built or published. To reuse one, copy the relevant file back into
`_posts/` (or just copy the frontmatter/snippet you need) and rename it with a current
date, e.g. `YYYY-MM-DD-my-post.md`.
